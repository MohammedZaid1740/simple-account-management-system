Bank Account Management System

About the Project

A simple Java OOP project that demonstrates basic bank account management using classes and objects.

Features

Create bank accounts with account number, account holder name, and balance.

Deposit money into an account.

Withdraw money from an account.

Check and display account details.

Maintain independent balances for different accounts.

Display an insufficient balance message when withdrawal exceeds the available balance.
